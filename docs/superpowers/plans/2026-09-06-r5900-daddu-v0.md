# R5900 DADDU v0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add native R5900 `DADDU` support through decoder, `Add64` IR, interpreted execution, Windows x64 execution and dispatcher startup progression beyond guest PC `0x00114edc`.

**Architecture:** Keep the existing decoder -> IR -> validator -> reference executor -> Windows x64 backend -> cached dispatcher pipeline. `DADDU` gets a dedicated `Add64` IR opcode because `AddWordSignExtend` intentionally models 32-bit word arithmetic; native execution is checked against the reference executor before dispatcher eligibility is enabled.

**Tech Stack:** C++20, CMake 3.25+, Visual Studio 2022/MSVC x64, Windows Server 2022 CI, CTest.

**Spec:** `docs/superpowers/specs/2026-09-06-r5900-daddu-v0-design.md`

## Global Constraints

- Work only on `design/r5900-daddu-v0`, based on `feature/r5900-or-v0 @ 9cfe55f9b3a68038849f20084ac9e30c00adc54e`.
- Do not modify `main`, merge PR #22, or move `feature/r5900-or-v0` without explicit integration authorization.
- Do not commit Burnout 3 ELF bytes, raw words copied from the game, assets, dumps, symbols or other proprietary data.
- Synthetic tests may use public MIPS/R5900 ISA encodings assembled from test fields.
- `DADDU` computes `uint64_t(GPR[rs].low64 + GPR[rt].low64)` modulo `2^64`, with no overflow trap.
- For `rd != 0`, write only `GPR[rd].low64`; preserve `GPR[rd].high64`.
- For `rd == 0`, lower to the existing provenance-preserving `Nop` convention.
- Do not alter `AddWordSignExtend` or add `DADD`, `DADDI`, `DADDIU`, `DSUB`, `DSUBU`, `SW`, graphics, audio, input or unrelated ISA work.
- Every production change follows RED -> GREEN and receives a focused commit.
- Never claim the game boots or is playable from this milestone.

R5900IrValidationResult validate_add64(const R5900IrInstruction& ir,
                                       std::size_t index) {
    const auto destination = validate_gpr_destination(
        ir, index, R5900IrGprWriteMode::Low64PreserveUpper64);
    if (!destination.ok()) return destination;
    if (ir.inputs.size() != 2u) {
        return failure(R5900IrValidationError::MalformedInstruction,
                       index, ir.guest_pc,
                       "Add64 expects exactly two GPR inputs");
    }
    for (const auto& operand : ir.inputs) {
        const auto validation = validate_operand(operand, index, ir.guest_pc);
        if (!validation.ok()) return validation;
        if (operand.kind != R5900IrOperandKind::Gpr) {
            return failure(R5900IrValidationError::MalformedInstruction,
                           index, ir.guest_pc,
                           "Add64 expects exactly two GPR inputs");
        }
    }
    return {};
}
