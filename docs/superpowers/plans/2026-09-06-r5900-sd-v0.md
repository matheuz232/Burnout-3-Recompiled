# R5900 SD / Store64 + EE Main RAM v0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Advance Burnout 3 startup beyond `SD ra,0(sp)` at `0x0011510c` by backing the 32 MiB EE main RAM and implementing R5900 `SD` as a native/interpreted `Store64` operation with exact fault provenance.

**Architecture:** `Ps2MemoryMap` owns one zero-filled 32 MiB EE RAM backing while `regions()` remains ELF `PT_LOAD` metadata. `SD` lowers to `R5900IrOpcode::Store64`, uses a new `write64` execution callback parallel to `write128`, and executes through the same helper-frame architecture in the Windows x64 backend. The dispatcher wires both callbacks and treats `SD` as v0-eligible without changing the previously fixed boundary-prefix rule.

**Tech Stack:** C++20, CMake 3.25+, Visual Studio 2022/MSVC x64, GitHub Actions Windows Server 2022, existing R5900 decoder/IR/executor/x64 backend/dispatcher and `Ps2MemoryMap`.

**Spec:** `docs/superpowers/specs/2026-09-06-r5900-sd-v0-design.md`

## Global Constraints

- Windows 10/11 x64 native runtime only; no PCSX2 runtime dependency.
- Keep C++20 and the existing CMake/Visual Studio 2022 build.
- Never commit proprietary Burnout 3 ELF/game bytes/assets.
- EE main RAM v0 is exactly `0x00000000..0x01ffffff` (32 MiB, exclusive end `0x02000000`).
- `Ps2MemoryMap::regions()` continues to report only ELF `PT_LOAD` metadata.
- `translate()` answers physical EE RAM availability and therefore succeeds outside `PT_LOAD` when the full range stays inside the 32 MiB EE RAM.
- `SD` stores exactly `GPR[rt].low64`; `GPR[rt].high64` is ignored.
- `SD` effective address is `uint32(low32(GPR[rs].low64) + sign_extend16(immediate))`.
- `SD` requires 8-byte alignment; do not round the address down.
- Failed `SD` reports `MemoryAccessFailure` at the exact guest PC/address with width `8`, mutates no guest memory, and executes no later guest instruction.
- Existing `SQ`/`Store128` semantics remain unchanged, including 16-byte address normalization.
- `main`, the PR #22 base branch, and PR merge state must not be modified implicitly.
- Integration into `feature/r5900-or-v0` requires explicit user authorization after final verification.
- Do not claim the game boots or is playable.

```cpp
R5900IrValidationResult validate_store64(const R5900IrInstruction& ir,
                                         std::size_t index) {
    if (ir.destination.has_value() ||
        ir.write_mode != R5900IrGprWriteMode::None) {
        return failure(R5900IrValidationError::MalformedInstruction,
                       index, ir.guest_pc,
                       "Store64 must not have a destination or GPR write mode");
    }
    if (ir.inputs.size() != 3u ||
        ir.inputs[0].kind != R5900IrOperandKind::Gpr ||
        ir.inputs[1].kind != R5900IrOperandKind::Gpr ||
        ir.inputs[2].kind != R5900IrOperandKind::Immediate) {
        return failure(R5900IrValidationError::MalformedInstruction,
                       index, ir.guest_pc,
                       "Store64 expects base GPR, value GPR, signed immediate");
    }
    if (ir.inputs[0].gpr_index >= 32u || ir.inputs[1].gpr_index >= 32u) {
        return failure(R5900IrValidationError::InvalidRegister,
                       index, ir.guest_pc,
                       "Store64 GPR index out of range");
    }
    if (ir.inputs[2].immediate < -32768 || ir.inputs[2].immediate > 32767) {
        return failure(R5900IrValidationError::MalformedInstruction,
                       index, ir.guest_pc,
                       "Store64 immediate must fit signed 16 bits");
    }
    return {};
}
```

```cpp
void emit_store64(std::vector<std::uint8_t>& bytes,
                  const R5900IrInstruction& instruction) {
    emit_reload_state_and_context(bytes);

    // Publish exact guest PC through execution context.
    bytes.insert(bytes.end(), {0x48u, 0x8bu, 0x44u, 0x24u, 0x28u});
    bytes.push_back(0xc7u);
    bytes.push_back(0x80u);
    emit_u32(bytes, current_memory_guest_pc_offset());
    emit_u32(bytes, instruction.guest_pc);

    // EDX = low32(base) + signed16(offset), modulo 32 bits. No alignment mask.
    emit_load_eax_from_state(bytes,
        gpr_low64_offset(instruction.inputs[0].gpr_index));
    bytes.push_back(0x05u);
    emit_u32(bytes, static_cast<std::uint32_t>(
        static_cast<std::int32_t>(instruction.inputs[2].immediate)));
    bytes.insert(bytes.end(), {0x89u, 0xc2u});

    // R8 = source low64.
    bytes.insert(bytes.end(), {0x4cu, 0x8bu, 0x81u});
    emit_u32(bytes, gpr_low64_offset(instruction.inputs[1].gpr_index));

    // RCX = execution context.
    bytes.insert(bytes.end(), {0x48u, 0x8bu, 0x4cu, 0x24u, 0x28u});
    emit_mov_rax_imm64(bytes,
        static_cast<std::uint64_t>(reinterpret_cast<std::uintptr_t>(
            &r5900_native_store64)));
    bytes.insert(bytes.end(), {0xffu, 0xd0u});
    bytes.insert(bytes.end(), {0x84u, 0xc0u});

    bytes.insert(bytes.end(), {0x0fu, 0x85u});
    const auto success_rel32_offset = bytes.size();
    emit_u32(bytes, 0u);

    emit_xor_eax_eax(bytes);
    emit_helper_frame_epilogue(bytes);
    bytes.push_back(0xc3u);

    const auto success_offset = bytes.size();
    const auto branch_end = success_rel32_offset + sizeof(std::uint32_t);
    patch_u32(bytes, success_rel32_offset,
              static_cast<std::uint32_t>(static_cast<std::int32_t>(
                  static_cast<std::int64_t>(success_offset) -
                  static_cast<std::int64_t>(branch_end))));

    emit_reload_state_and_context(bytes);
}
```
